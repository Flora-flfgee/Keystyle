# Keystyle Sartorial Web Site

A premium, modern web showcase built for **Keystyle Sartorial**, featuring elite image consulting and niche makeovers for the Modern Gentleman.

## ✨ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Architecture**: Glassmorphism and minimalist design with custom components.

## 🚀 Quick Start

1. **Clone & Setup**:
   ```bash
   git clone https://github.com/floraleong2025/keystyle_web.git
   cd keystyle_web
   npm install
   ```

2. **Run Dev**:
   ```bash
   npm run dev
   ```

3. **Build & Start**:
   ```bash
   npm build
   npm start
   ```

## 🏗️ Structure

- `/src/app`: Page layouts and routing.
- `/src/components`: UI sections (Hero, Services, Testimonials, etc.).
- `/src/lib`: Reusable helper utilities.
- `/docs`: Detailed project documentation.
